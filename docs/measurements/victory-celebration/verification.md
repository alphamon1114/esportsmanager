# 우승 축하 화면 — 2026-09-20

- 자신의 팀이 대회 결승 BO5를 최종 승리하면 기존 결과 화면보다 먼저 축하 화면을 표시한다. 다른 팀의 우승이나 개별 맵/준결승 승리에는 표시하지 않는다.
- 금색 트로피, `CONGRATULATIONS!`, 우승 팀 이름, 한국어/영어 축하 문구와 메인으로 버튼을 표시한다. 트로피는 UI 도형으로 그려 외부 이미지나 이모지 폰트에 의존하지 않는다.
- 메인으로를 누르면 메인 메뉴으로 이어진다. 확인 여부는 대회 저장 데이터의 `victoryCelebrationSeen`에 저장하며 새 대회는 기본값 false로 시작한다. 이전 저장 파일에도 기본값 false를 적용한다.
- `VictoryCelebrationChecks`에서 최종 우승 이전 표시 방지, 자신의 팀 우승, 다른 선택 팀의 새 대회, 상대 우승 제외, 중복 닫기와 결과 보존을 확인했다. 테스트 전용 저장 키를 사용하므로 사용자의 대회 저장을 덮어쓰지 않는다.
- Headless 검사 통과 및 Unity 6000.6.0f1 실제 API 어셈블리 컴파일 성공. Unity 전용 저장/불러오기 분기는 이번 headless 실행에 포함되지 않았으며, 실제 Unity 화면에서의 수동 조작 검사는 수행하지 않았다.
- `victory-preview.png`는 실제 화면 배치/도형 코드를 호출한 구성 미리보기다. 텍스트는 별도 렌더러로 출력했으므로 Unity 직접 캡처와 글꼴 렌더링에 차이가 있을 수 있다.
