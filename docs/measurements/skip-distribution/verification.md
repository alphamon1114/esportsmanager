# 스킵 킬 편중 수정 — 2026-09-20

## 원인과 변경

기존 스킵은 매 탄마다 양 팀에서 무작위 선수를 뽑고, 능력치 제곱·무기 가격·남은 체력으로 사격자를 정했다. 무기별 발사 간격과 빗나감은 반영하지 않았다. 소총은 매번 다른 적에게 피해를 나눠 주는 반면 AWP는 한 발로 킬을 얻기 쉬웠으며, 가격 보정까지 사격 기회를 늘렸다.

`StatExchange`는 선수별 다음 발사 시각을 관리한다. 실제 무기 프로필의 발사 간격·장전 시간·탄약을 반영하고, 상대가 죽을 때까지 표적을 유지한다. 표적 재선정에는 반응 시간이 필요하다. 능력치와 무기 정확도로 명중/빗나감을 계산한다. 킬을 다른 선수에게 재분배하거나 선수별 상한을 두지 않는다. 기존 `StatShot` 피해·사망 이벤트를 통해 KDA/경제를 계속 기록한다.

라운드 스킵과 경기 스킵이 모두 사용하는 `AdvanceStatSkip`에 적용했다. 맵 이동·실제 시야를 재생하는 기능은 아니며, 빠른 통계 시뮬레이션이다. 일반 관전 경기의 사격 로직은 변경하지 않았다.

## 비교 측정

기존 코드와 변경 코드를 각각 컴파일해 같은 기본 로스터, 같은 날짜 컨디션, 같은 30개 시작 시드로 전체 맵을 라운드 스킵했다. 구매·경제·진영 교대·KDA 집계를 포함한다. 팀 기록은 양쪽을 합쳐 60개다. 이는 이 표본의 비교이며 모든 팀/시드에서 같은 분포를 보장하지 않는다.

| 지표 | 변경 전 | 변경 후 |
|---|---:|---:|
| 팀 내 최다킬 선수의 평균 팀 킬 비중 | 43.4% | 28.2% |
| 한 선수가 팀 킬의 50% 이상인 팀 기록 | 18 / 60 | 0 / 60 |
| AWPER 역할 선수의 전체 킬 비중 | 43.7% | 20.0% |
| 표본 내 한 선수의 최다 맵 킬 | 48 | 23 |
| 전체 킬 | 2,667 | 3,107 |

동일 능력치·방어구, 팀당 AWP 1명/AK 4명의 통제 실험 4,000라운드에서는 AWP의 전체 킬 비중이 58.7%에서 16.5%로 바뀌었다. 실제 로스터/구매가 포함된 위 표와 조건이 다르다.

## 검증

- `StatDistributionChecks`: 동일 조건 선수의 명단 순서 편향, 능력치 효과, 결정적 재현, 무기 발사 간격, 장전 대기, 탄약 소모, 표적 유지, 자연적인 5킬 허용, 라이브에서 이미 시작한 장전 승계.
- `FastForwardChecks`: 라운드/진행 중 라운드/AI BO3 스킵, 기존 킬 보존, KDA·경제·탄약, 다음 구매 단계, 타임아웃, 취소, 동일 시드 재현.
- `MatchStatisticsChecks`: 피해·어시스트·트레이드·생존·진영 집계 및 중복 종료 방지.
- Unity 6000.6.0f1 실제 API 어셈블리 대상 전체 게임/에디터 스크립트 컴파일. 기존 obsolete/unused 경고만 발생했다.

전체 회귀나 Unity 화면 수동 검사는 실행하지 않았다. 로그: `checks.log`, `before.log`, `after.log`, `unity-compile.log`. 비교 측정 코드는 `Measure.cs`이며 Assets 밖에 보관하여 게임 빌드에는 포함되지 않는다.
