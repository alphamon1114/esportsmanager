# FPS Manager — 더미 프로토타입

Unity 6000.6.0f1. Assets/Scenes/Prototype.unity를 열고 Play를 누른다.

## 사용 순서
1. 지도 또는 오른쪽 선수 목록에서 선수를 선택한다.
2. Initial zone의 버튼으로 담당 구역을 지정한다. CT는 B 사이트 / 중앙·아치 / A 사이트, T는 바나나 / 중앙 / 아파트다.
3. Start movement test를 누르면 두 팀이 스폰에서 지정 구역으로 이동한다. 시작 후 배치 변경은 잠긴다.
4. 선수 선택은 이동 중에도 가능하며 1인칭 카메라가 따라간다. Pause / Resume으로 관전을 멈출 수 있다.
5. Reset to preparation으로 스폰과 시간을 초기화한다. 준비 단계의 Swap starting sides로 진영을 교환한다.

## 구현
- 스피릿·팔콘즈 선수 10명, 기본 스탯과 총기 숙련도 데이터.
- 큐브 지형·엄폐물과 캡슐 선수. 2D·1인칭 카메라는 같은 월드를 사용한다.
- 캡슐 반경을 고려한 격자 경로 탐색, 벽·엄폐물 회피, 서로 다른 도착 지점 배정.
- 5명이 한 구역에 배치되는 구성도 허용. 기본 역할은 배치를 제한하지 않는다.
- 그래픽·UI는 더미 유지. 선수의 판단·행동 텍스트는 표시하지 않는다.

## 아직 없는 기능
사격·적 탐지·투척물·라디오·구매·경제·점수·타임아웃·폭탄·승패 판정은 미구현이다.
이동 완료 후 자동으로 전투나 다음 라운드를 시작하지 않는다. 이동 중 선수끼리의 충돌 회피도 아직 없으며 경로가 겹치면 서로 통과할 수 있다.
현재 이동 속도는 테스트용 고정값이며 무빙 스탯 보정은 적용하지 않는다.

## 검증
Editor의 DeploymentChecks.Run 배치 실행으로 양쪽 시작 진영에서 분산 배치 및 각 구역 5인 집중 배치 등 8개 구성을 확인한다.
검사 항목: 스폰·이동 중 지형 관통 여부, 경로 완주, 시작 후 명령 잠금, 시점 선택.
그래픽 렌더링은 별도 Play 확인 대상이다.

## 데이터
Assets/Resources/teams.json이 Unity 로딩용 데이터다. 수치는 게임용 초기 추정치이며 IGL 보너스 적용 전이다.
